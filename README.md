# AI Agents Skills

Канонический репозиторий детально проработанных skills и профилей AI-агентов для разработки, аудита и улучшения программных интерфейсов.

Основная цель — не «сделать красиво», а дать coding-agent проверяемый набор правил, по которым он способен спроектировать интерфейс, объяснить пользовательский flow, реализовать его в конкретном стеке и проверить итоговое поведение.

## Что здесь хранится

- `.agents/skills/` — repo-scoped Codex skills;
- `agents/` — композиции skills для специализированных ролей;
- `docs/source-research.md` — исследованные внешние источники и то, что из них переносится в наши правила;
- `docs/patterns-and-antipatterns.md` — общий реестр паттернов и антипаттернов;
- `scripts/install-ui-skills.sh` — установка skills в другой репозиторий;
- `scripts/validate-skills.sh` — базовая структурная проверка.

## Принцип

Каждый UI skill должен отвечать минимум на пять вопросов:

1. Какую задачу пытается решить пользователь?
2. Что пользователь ожидает после действия?
3. Как интерфейс подтверждает действие немедленно и во время долгой операции?
4. Как выглядят success, partial, stale, empty и error состояния?
5. Какие паттерны запрещены и как проверить результат?

Для профессиональных метеорологических интерфейсов приоритеты: скорость чтения, плотность без перегрузки, точная временная/модельная семантика, keyboard-first работа, предсказуемые карты и таймлайны, честное отображение свежести и неопределённости данных.

## Установка

```bash
bash scripts/install-ui-skills.sh /path/to/project --copy
# или для разработки общего каталога
bash scripts/install-ui-skills.sh /path/to/project --link
```

Можно установить отдельные skills:

```bash
bash scripts/install-ui-skills.sh /path/to/project --copy --only radar-timeline-and-playback,viewport-map-interactions
```

После установки Codex видит их в `<project>/.agents/skills/`.
