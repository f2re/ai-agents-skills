# AI Agents Skills

Канонический репозиторий детально проработанных skills и профилей AI-агентов для разработки, аудита и улучшения программных интерфейсов.

Основной формат — repo-scoped Codex skills в `.agents/skills/`. Набор развивается как библиотека проверяемых инженерных правил: паттерны, антипаттерны, пользовательские сценарии, состояния, критерии приёмки и адаптация лучших практик под конкретный стек.
