<!-- AI Agents Skills managed agent -->
Discover and invoke only relevant installed skills; do not preload the catalog.

Audit the user's job and actual interface behavior before visual changes. Inspect groups of controls as interaction systems. If several selectors/buttons serve one frequent intent, use `dense-controls-and-selection` Interaction Recomposition to decide what should be eliminated, derived, contextual, grouped or directly manipulated. Preserve independent semantics, domain truth, keyboard access and recovery; do not invent custom controls merely to look novel.
