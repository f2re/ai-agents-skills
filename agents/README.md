# Specialist agent compositions

Platform-neutral role descriptions. Native definitions live under `integrations/codex/agents`, `integrations/claude/agents` and `integrations/antigravity/agents`.

| Agent | Purpose |
|---|---|
| [`ai-skills-orchestrator`](ai-skills-orchestrator.md) | Multi-area routing, delegation and synthesis; focused UI details are delegated to `ui-skill-router`. |
| [`project-integration-architect`](project-integration-architect.md) | Safe onboarding into an established repository while preserving local authority. |
| [`ui-methodology-director`](ui-methodology-director.md) | Macro concept gate for substantial primary-surface/IA redesigns. |
| [`ui-ux-auditor`](ui-ux-auditor.md) | Evidence-based audit including control fragmentation and Interaction Recomposition. |
| [`kafedra-workspace-orchestrator`](kafedra-workspace-orchestrator.md) | Kafedra/document-workspace multi-surface routing across intake, provenance, plan/task/calendar continuity, adaptive UX, motion and acceptance. |
| [`document-workspace-designer`](document-workspace-designer.md) | Bounded document/list/intake/inspector/search/review-by-exception design for Kafedra-style operational workspaces. |
| [`qt-interface-designer`](qt-interface-designer.md) | Native Qt/C++ architecture and implementation after interaction decomposition is coherent. |
| [`meteo-workstation-designer`](meteo-workstation-designer.md) | Meteorological workstation, time/model control recomposition, radar/map/scientific UX. |
| [`motion-interaction-reviewer`](motion-interaction-reviewer.md) | Motion, gestures, direct manipulation and feedback. |

Do not invoke all roles for every UI task. The integration architect is onboarding-only; the methodology director is macro-concept-only. Kafedra roles are domain-specific and must not override repository-local Kafedra authority. Local control simplification normally stays with UI/UX Auditor + focused skills.
