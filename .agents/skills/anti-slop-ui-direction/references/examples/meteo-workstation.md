# Example ladder: meteorological workstation

## SLOP

- top row of large cards: Temperature, Humidity, Pressure, Wind, CAPE, Rain;
- dark blue gradient and large rounded containers;
- map reduced to one card among many;
- model/run/valid time hidden in dropdowns;
- every plot has an independent tooltip and time state.

It may look modern, but the layout could become a finance/SaaS dashboard by relabeling cards.

## DECENT

- large map;
- compact left toolbar/selector;
- meteorogram below or beside the map;
- readable typography and consistent controls;
- model and valid time shown.

This is usable but may still be only a clean arrangement of components.

## PROFESSIONAL

Defining mechanism: **SELECTION DRIVES ALL VIEWS** supported by **TIME IS THE SPINE**.

- the selected location/feature is one explicit shared state;
- map, meteorogram, inspector and derived diagnostics describe that same selection;
- one valid-time cursor synchronizes related plots and map time;
- observation → now → forecast provenance is visible;
- model/run/source/freshness remain immediately discoverable;
- rare configuration moves to contextual inspector/progressive disclosure;
- resizing preserves map/plot priority instead of proportionally shrinking every panel.

The interface is recognizably meteorological even without decorative weather imagery.
