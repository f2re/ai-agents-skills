# Example ladder: forecast model comparison

## SLOP

- one large model dropdown;
- one selected model plotted at a time;
- model metadata displayed as internal center/identity IDs;
- summary cards announce "best model" without visible evidence.

The interaction asks the user to configure a model before seeing the comparison they actually need.

## DECENT

- several model curves overlaid on one plot;
- human-readable model names;
- shared time axis and legend;
- click a model to emphasize it.

## PROFESSIONAL

Defining mechanism: **MODEL DISAGREEMENT IS DATA** supported by **UNCERTAINTY HAS GEOMETRY**.

- consensus/median or selected reference is visually stable;
- spread/divergence is an explicit envelope or difference geometry;
- outlying models remain traceable without dominating the plot;
- one shared crosshair gives exact values for the same valid time;
- run/cycle/lead semantics remain visible;
- model selection is secondary to understanding agreement and transition points;
- missing model terms are shown as missing, not interpolated into false certainty.

The primary question becomes "where and when does the forecast become unstable?", not "which dropdown item is active?".
